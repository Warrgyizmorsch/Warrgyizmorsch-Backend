# Language Guidelines for CRM

- **Strict English Only**: All user-facing UI text, buttons, form placeholders, labels, table headers, validation messages, flash notifications, toasts, alerts, and modal popups (including `appConfirm`, `Swal.fire`, `alert()`, `confirm()`) must ALWAYS be written in clean, standard, professional English.
- **No Hinglish or Hindi**: Do not use Hinglish or Roman Hindi words anywhere in the application code, frontend templates, Blade views, JavaScript, or backend response messages.
